Prerequisite: Complete KB2948102 first. Your workspace at ~/my-claude-workspace/ must exist and be configured before running the installer below.

Step 1 — Place attachment files in your workspace root

Download all attachments from this article and move them into ~/my-claude-workspace/:

MFR_GENERIC.txt   SP_GENERIC.txt   DEV-TASK_GENERIC.txt   skills.zip   SendToClaudeExtension.zip

Step 2 — Load the extension in Chrome

  1. Extract SendToClaudeExtension.zip inside your workspace root. The resulting folder (~/my-claude-workspace/SendToClaudeExtension/) is the extension's permanent home — do not move it after loading.
  2. Open chrome://extensions, enable Developer mode (top-right toggle), click Load unpacked, and select the SendToClaudeExtension folder.

Step 3 — Run the installer

In Terminal, run:

~/my-claude-workspace/SendToClaudeExtension/setup.sh

The installer moves your template files into prompts/, extracts skills into .claude/skills/, clones the ServiceNow documentation library into md/ServiceNowDocs/, configures the Chrome native messaging host, and smoke-tests the connection. When it finishes with Setup complete, everything is ready.

Step 4 — Verify

  1. Reload the extension in chrome://extensions/.
  2. Right-click the extension icon → Options. The Status card should show Host: ok ✓ with your workspace path.
  3. Open any ServiceNow case or task. The Send to Claude button appears in the navbar. Clicking it ingests the record into cases/CS<n>/ inside your workspace — PDF, attachments, tasks, and a populated tracker.md.

Tip — Name sessions by case number for easy resume

  1. Start a session for a case: Launch Claude Code from your workspace, then run /rename CS0000000 (replace with your case number).
  2. Alternatively, name it at launch: From Terminal, run claude --name CS0000000.
  3. Resume a case session later: From Terminal, run claude --resume — select your case number to pick up exactly where you left off.

Most case investigations span multiple sittings. Naming sessions by case number keeps your work organized and eliminates re-explaining the situation each time you return.
