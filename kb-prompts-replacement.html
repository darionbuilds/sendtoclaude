Run setup.sh before using these prompts — it handles all file placement automatically. These prompts cover the personalization steps that follow: substituting your name into templates, building your product doc index, and customizing your skills.

Prompt 1 — Workspace Scaffold

Use immediately after running setup.sh. Your template files are already in prompts/ — this prompt substitutes your name and adds the required rules to CLAUDE.md.

I'm setting up a Claude Code workspace for ServiceNow TSE casework. Please complete the following steps automatically:

1. Create the md/ directory inside my workspace root if it doesn't already exist.

2. Ask me for my name. Then read the following files from my prompts/ directory and rewrite each one in place, replacing every instance of [Your Name] with the name I provide:
   - prompts/MFR_GENERIC.txt
   - prompts/SP_GENERIC.txt
   - prompts/DEV-TASK_GENERIC.txt

3. Open my CLAUDE.md and add the following two rules under a new section called "Workspace Extensions":
   - Lookup priority: Before answering any product question, check md/_index.md first. Only perform a web search if the topic is not covered in md/.
   - Template compliance: Before generating any customer-facing email (MFR or SP), read the relevant template file from prompts/ and follow it exactly — no added sections, no alternate tag formatting.

Confirm each step as it completes.

Prompt 2 — md/ Index Builder

Use after manually placing product documentation files in the md/ directory. Claude will generate the index and flag coverage gaps.

I've added product documentation files to the md/ directory in my Claude Code workspace. Please:

1. Read every file currently in md/ — skip _index.md if it already exists
2. For each file, identify the products, features, and topics it covers
3. Write md/_index.md as a markdown table with three columns: Product/Topic | File | Key Line Ranges — give a separate row per distinct product with the line range where that product's content begins and ends, specific enough to open directly
4. After writing the index, give me a one-line summary of what each file covers and flag any topics a ServiceNow TSE would expect to reference that aren't represented

Prompt 3 — Skills Customization

Use after running setup.sh, which has already extracted your skills into .claude/skills/. Complete Prompt 1 first so templates are in place. This prompt personalizes the skills with your details.

My skills have already been extracted into .claude/skills/. Please:

1. Read all skill files in .claude/skills/
2. Ask me for the details needed to personalize them — my name, squad, product areas, and anything else you identify as engineer-specific
3. Once I confirm those details, update each skill file accordingly and let me know what changed
